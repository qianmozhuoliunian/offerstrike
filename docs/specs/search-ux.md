# 规格：搜索结果浏览体验与高级交互规范

- 状态：已完成
- 最后更新：2026-11-11

## 问题与目标

求职者在搜索目标岗位面经时，面临两大体验痛点：
1. **长图文内容过度挤占版面**：面经爬取文本长度差异极大，若全部展开导致长图文严重占屏、翻阅费力；若机械截断或采用原生 details 瞬间闪现展开，产生突兀下推与闪烁，违背交互平滑性。
2. **关键动作缺乏触感确认**：在筛选面经（如点击 + 收藏来源）与复盘录题（如勾选将此面试问题加入个人题库）等高价值行为发生时，缺乏物理质感的动效反馈，操作确认感弱。

目标：依据《Advanced Interaction Design》高级交互设计规范，遵循任务驱动、选 1 主交互 + 至多 1 辅助交互、平滑阻尼过渡 0 、全微交互闭环的原则，重构搜索与决策链路。

## 交互模式定位与业务关系

### 1. 主交互 (Primary Interaction)：Animated Text Disclosure (阻尼手风琴展开)
- **业务场景**：搜索卡片长篇面经正文与试题列表的深度查阅。
- **设计规则**：
  - 默认展示 200 字纯净精简摘要（剥离爬虫 markdown 符号杂质）。
  - 超出 200 字时，渲染胶囊状折叠摘要按钮，带平滑旋转的 Chevron 箭头。
  - 展开与折叠采用 CSS Grid (grid-template-rows: 0fr <-> 1fr) 与衰减阻尼曲线 cubic-bezier(0.16, 1, 0.3, 1)，过渡时长 0.22s，杜绝任何生硬突兀跳变。
- **三阶段生命周期**：
  - **开始状态**：展示截断预览与浅蓝胶囊标签查看完整摘要，箭头处于 0° 朝下。
  - **发酵过程**：点击时胶囊轻微按压弹性收缩 (scale(0.96))；内容区以 0.22s 贝塞尔阻尼由上至下滑入展开，透明度 0 -> 1，Chevron 顺时针旋转 180°。
  - **收尾闭环**：内容稳态定格在带细腻浅灰边框的阅读容器中，最大高度 240px 并开启内滚动；再次点击时反向执行 0.20s 阻尼收拢并平滑重置箭头，文本无闪失。

### 2. 辅助交互 (Secondary Interaction)：Spring Micro-Interactions (弹性微交互)
- **业务场景**：高价值动作确认——个人复盘勾选加入个人题库（Checkbox）及搜索结果+ 收藏来源（Button）。
- **设计规则**：
  - Checkbox 自定义化，摆脱原生生硬开关；点击时具有 scale(0.86) 物理弹性压缩，勾选瞬间执行 scale(1.12 -> 1) 弹簧回弹 (cubic-bezier(0.34, 1.56, 0.64, 1))，白色对勾自中心弹性绘制放大。
  - 收藏按钮与分段控制器（Segmented Control）在 :active 下压时触发 scale(0.94) 触感压缩，释放后弹回；收藏成功触发 springSavePop 弹簧气泡动效。
- **主辅关系**：
  - **主交互掌控输入与消费**：解决大篇幅面经的快速筛选与低认知负荷阅读；
  - **辅助交互掌控决策与沉淀**：在求职者决定收藏或沉淀试题时，给予确定性的物理触感反馈；
  - 二者构成平滑浏览 -> 笃定沉淀的高粘性闭环。

## 范围与取舍

- **包含**：
  - 搜索结果卡片的长篇摘要平滑展开收起。
  - 全局复选框（Checkbox）及按钮/分段选择器的弹簧微动效。
  - 岗位相关性安全过滤（前端岗位自动过滤明显 Java/后端内容）。
  - 骨架屏加载与收藏即时状态持久化。
- **不包含**：
  - 不修改后端数据库结构与真实面经抓取源。
  - 不引入沉重的第三方动画库，纯原生 CSS3 + 极简事件委托驱动，零外部依赖，极致性能无卡顿。
