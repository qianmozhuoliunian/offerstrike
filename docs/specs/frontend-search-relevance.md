# 规格：前端岗位搜索结果相关性

- 状态：已完成
- 最后更新：2026-11-11

## 问题与目标

目标岗位为前端时，搜索结果包含标题明确为 Java 后端的帖子。降低明显不匹配结果对面经浏览的干扰。

## 范围与取舍

- 对前端岗位，仅依据标题保守识别明确的 Java 或后端帖子；标题同时提到前端时保留。
- 标题未明确表明前端且未明确冲突的帖子保留并标记岗位待核实；不根据摘要推断真实性。
- 提示过滤数量，避免将过滤视为搜索服务没有返回结果。其他岗位行为保持不变。
- 规则无法判断全部语义，可能漏掉不匹配或误过滤；原帖仍须核实，不承诺搜索准确率。

## 验收与验证

| 标准 | 验证 | 结果 |
| --- | --- | --- |
| 前端搜索排除标题明确为 Java 后端且没有前端标记的帖子 | 固定样本与真实搜索 | 固定样本通过；重试时上游未返回此类标题，无法确认本次实际过滤 |
| JavaScript、前后端混合和岗位不明确的帖子不因此被排除 | 固定样本 | 通过 |
| 其他岗位结果不受前端规则影响，来源和时间筛选仍生效 | 固定样本及现有测试 | 测试通过 |

## 数据与外部服务

沿用 Tavily 请求和现有数据流；本次不改变数据库或岗位配置。

## 验证记录

自动化测试 38 项通过。重启后真实前端搜索返回 13 条结果，未见标题明确为 Java 后端的结果；上游返回内容可能变化，结果仍需逐条核实。
