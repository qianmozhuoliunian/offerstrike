# 规格：用 FastAPI 执行面经检索

- 状态：已完成
- 最后更新：2026-11-13

## 目标与范围

为后续 Python Research Agent 建立可独立运行和测试的检索接口。Node 暂时继续决定什么时候补搜、怎样过滤和去重，继续负责用户主动选择的 AI 判断；Python 执行一轮指定供应商的检索。保留原生 Node 路径作回退，不复制面经相关性规则。不开启时无需安装 Python。

## 验收

- 设置 `RESEARCH_SERVICE_URL` 后，Node 通过本机 FastAPI 检索；不设置则走原有路径。Python 不可用时给出提示，不自动重发给外部服务；移除该配置并重启 Node 可切回原路径。
- Python 只接收供应商、已确认的岗位、公司、允许的站点、时间和固定查询方式。只连接固定的 Tavily / Exa 地址，API 密钥从 Python 环境读取；不接收 JD、简历、作答、任意 URL 或密钥。
- FastAPI 校验输入，拒绝非法的站点、日期和字段，限时调用上游并明确报告失败。Node 保留搜索结果分组、补搜上限、来源和时间筛选、去重及失败提示。
- 以模拟上游测试独立 FastAPI 接口与 Node 接入，核对出站请求和错误。用隔离数据验证两进程连通。

## 数据影响

Python 监听本机，不读取或写入 SQLite。Node 仍是唯一数据所有者；无数据库迁移或备份格式变动。用户网页继续调用既有 `/api/search`。

## 验证记录

- Node 111 项、FastAPI 14 项自动化测试通过，包含参数约束、两家供应商请求映射、隐私字段及失败路径。
- 使用隔离数据库、独立 Node 和 FastAPI 监听端口，以及模拟 Tavily，验证了搜索、合并重复结果和 FastAPI 停止时的 502 提示。
- 通过 FastAPI 实际调用 Tavily 一次（产品经理、牛客、不限时间），收到 HTTP 200 和 15 条供应商候选；未核对原帖，也未实测 Exa。此次不评估面经相关性。
