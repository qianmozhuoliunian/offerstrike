# 规格：明确搜索时发送的内容

- 状态：已完成
- 最后更新：2026-11-11

## 问题与目标

搜索服务实际只接收岗位要求的前 800 个字符，但页面没有说明；公司关键词超过 100 个字符时也会被静默截断。这违反项目约定，并可能让用户误以为完整要求参与了搜索。

## 范围与验收

- 搜索前持续展示：目标岗位、公司和已确认岗位要求会发送给 Tavily；岗位要求最多发送前 800 个字符，不足时全部发送。
- 公司关键词超过 100 字符时明确拒绝，不静默截断；页面也限制输入长度。
- 岗位要求按 Unicode 字符截取，避免截断代理对；保持已有岗位资料和数据库内容不变。
- 用自动化测试覆盖边界、长要求、表情和超长公司名，核对页面提示与实际发送范围一致。

## 数据与外部服务

沿用现有 Tavily，不新增外部服务或保存内容；只改变输入校验、截取边界和信息提示。

## 验证记录

- 2026-11-11：接口测试使用模拟搜索服务核对实际发送的 800 字符范围、表情边界及超长公司名；浏览器检查搜索页的持续提示。完整自动化测试 70 项通过。
