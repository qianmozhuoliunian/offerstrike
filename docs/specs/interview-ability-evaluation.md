# 规格：Interview Agent 结构化能力评价

- 状态：已完成
- 日期：2026-11-16

## 范围

在现有 Node 练习与多轮对话中，让同一次模型请求返回自然语言点评和可选结构化评价。保留八轮上限、用户可随时总结、题库题目关联和幂等行为。Career 提供当前岗位的只读能力历史，并将有依据的遗漏与错误用于复习计划。

## 证据与数据

每条评价属于一次作答，包含主题、正确点、错误或遗漏、未验证项、一条建议追问及建议行动。正确点和错误的证据为该次回答的连续原文。遗漏额外引用本轮原题的要求，并引用用户已经说出的相关内容来说明缺口。无法定位相关内容时用未验证项。主题须出现在本轮题目或回答中。追问若启用须指向一条薄弱点，去除重复追问并沿用既有轮次限制。

SQLite 迁移增加独立评价表，历史题意、作答、时间和题目关联沿用现有表。v1 JSON 备份增加可选评价字段，导入校验证据及所属作答。旧记录无评价时正常显示。模型格式或证据校验失败时保留已有的自然语言点评与流程，日志仅记失败类型。

## 接口与验收

- 通过既有练习接口保存与回读评价，沿用当前的 AI 提示与逐字证据规则验证结构化结果。页面展示可核对的证据，标出遗漏和未验证项。
- Career 的能力历史接口按当前岗位读取近期评价、重复问题、多轮支持、未验证项与下一步建议。聚合描述观察次数，复习提醒保留自评优先级。
- 验证错误字段的降级、多轮结束、旧库升级、重启、备份恢复、前端显示及真实 DeepSeek 请求。

## 实现与接口

- `ability-evaluation.js` 校验并保存单轮评价。点评里的明确观察须绑定当轮回答，遗漏还须绑定当轮题目。模型若给出含有原文首词的主题长标题，会保留可核对的主题词。没有可核对的主题时保留空值。追问缺少薄弱点、文字无效、重复或到达八轮时，仍保留可用的观察及自然语言点评。
- 对话、历史点评及备份沿用现有入口。新备份在版本 1 中带有可选的 `ability_evaluations`。数据库迁移到 v2，已有作答保持原样。
- `GET /api/career/ability-history?role=…` 返回当前已确认岗位最近 100 条有结构化评价的作答。`history` 含 `attempt_id`、时间、题目、`root_attempt_id`、题库引用、评价和主题来源轮次。追问若缺主题，按同一对话可核对的上游主题展示，保留原轮评价。`topics` 统计轮次数，`recurring_issues` 和 `repeated_strengths` 汇总相同主题与知识点文字下的多轮观察，`unverified` 保留最新未验证项，`next_steps` 给出可执行的复习主题。用户有明确自评或手选主题时沿用现有优先级。
- 聚合按规范化名称匹配，语义相同但文字不同的点可能分列。逐字证据能定位模型判断依据，模型判断的技术正确性仍需按实际样本复核。

## 验证结果

- 自动化通过 142 项 Node 测试和 22 项 FastAPI 测试。覆盖原文锚定、无效模型字段降级、重复追问、八轮结束、v1 迁移、备份恢复、题目关联、岗位隔离、Career 和前端点评渲染。Research 及来源确认入库回归通过。
- 真实 DeepSeek HTTP 验证使用 `deepseek-flash`、固定合成 RAG 问答和隔离 SQLite。最终运行首轮 2.90 秒，得到 1 个正确点、1 个明确错误、1 个遗漏和 3 个未验证项。追问针对增加召回数量后准确性下降的定位，第二轮 3.03 秒，点评与结构化观察均保存。总结请求 1.32 秒。重启服务后，两轮和总结与原响应一致，Career 将两轮关联到 RAG 并给出复习建议。第二轮模型未给出可执行的下一条追问，保存为复习建议，正常结束。模型账单未取得。
- 早期真实调用出现主题过长、追问目标未填等格式偏差。旧点评保持可用，改为独立校验建议行动与能力观察后，再完成以上真实验证。

可另行执行可选验收脚本。它只使用内置示例，在临时数据库上通过现有练习 API 处理函数运行两轮、总结与重开读回，并产生模型调用。

```powershell
node --env-file=.env scripts/interview-eval.mjs --live
```

脚本复跑时首次连接超时，重试通过。正式 HTTP 验证与脚本都使用真实模型。
