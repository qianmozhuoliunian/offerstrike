# 规格：Research 正文读取入口

- 状态：已完成
- 日期：2026-11-19

## 已证实的阻塞

原 20 组中保留 320 条线索。按旧处理顺序，82 条博客园 URL 未通过格式限制，62 条在标题岗位过滤处停止。跨平台内容、非面经及公司不明另列。旧记录未保存日期筛选前的搜索响应，不能凭原日志重建丢弃的结果。

小样本显示博客园无扩展名文章返回 200，同一文章的 .html 地址会跳回无扩展名。现有标题、类型及日期要求仍执行，正文日期未知或越界不能生成候选。牛客新帖部分只有空页面壳，暂不引入独立适配器。

## 改动与验收

1. 读取器接受博客园同一布局的数字无扩展名文章，保留原 URL，不接受目录、标签、任意重定向。
2. 搜索未给日期时可在现有读取预算内读取正文，只在正文元数据合格后提题。已明确越界的搜索日期继续拒绝。
3. 增加可选的筛选追踪回调，记录每个搜索结果的规范化、时间、标题、类型、读取预算等决定。用于本次诊断，不记录凭证、正文或用户数据。
4. 复用已有业务评估脚本执行 Research，沿用原 20 组，并增加独立来源样本。固定输入、分别保留优化前和优化后结果、可读页面与可信题目人工复核结果。

原文摘录、人工确认和公司归属规则继续适用。仅用读到的正文，不使用搜索摘要充当证据。不改变整体架构和调用预算。

## 验证

159 项 Node 回归通过，包括新旧 URL、缺日期后读正文、正文无日期／过期／未来时禁止提题、原有优先顺序，以及既有公司否定、跨章节与证据检查。

同一20组与4组独立样本已实际重跑。入口覆盖修复未带来可信题数增加，原20组依然14组零读取。详细逐条日志、试验中排序回退和真实超时均保留在[专项诊断](../research-reading-optimization-2026-11-20.md)。
