# v0.1.0 · 首次公开版本

见面（OfferPilot）是本机使用的面试准备工作台：按目标岗位找公开面经，核对原帖后收题，作答并自评，再查看下一次推荐。

## 本版包含

- 来源与题目关联，手动录题和有原文依据的 AI 候选确认。
- 本地作答、自评、按规则推荐，可选 AI 点评与追问。
- 岗位隔离、草稿恢复、真实面试复盘、JSON 备份与合并导入。
- Windows 桌面入口，以及不保存个人数据的独立静态演示。
- 首次使用引导、配置模板、MIT 授权与 GitHub 自动检查。

## 试用前了解

搜索需要用户自己的 Tavily 或 Exa 配置；AI 功能需要用户自己的兼容模型服务。无需配置也能管理来源、题库、作答与自评。服务调用按所选供应商计费。

搜索结果和 AI 判断需要核对。推荐依据自评、次数和时间，不代表系统测出了掌握度。深度研究与备战串练属于实验功能，当前自动读取仅支持博客园。

Windows 安装包未签名、没有自动更新，尚未验证干净机器安装；本地工作台不提供多人账号或公网部署支持。

## 维护者首发步骤

1. 在本机运行 `npm run check`；修改 Python 检索服务时另外执行其测试。人工核对待发布的文档、图片和提交作者信息，确认不含个人资料。构建包不应加入 Git。
2. 在 GitHub 创建空仓库，再关联本地仓库并推送。使用 `git branch --show-current` 确认当前分支；不要强制推送或把个人数据目录上传到仓库。
3. 等 GitHub Actions 的 Windows / Ubuntu 检查完成。到仓库 Security 设置中启用私密漏洞报告。
4. 从已核对的提交创建 `v0.1.0` 标签与 Release，可直接使用本文前面三节作为发布说明。发布前从该提交重新构建，不混用旧包。
5. Windows 构建用 `npm run desktop:build`，上传 `dist/windows/OfferPilot-Setup.exe` 与 `dist/windows/OfferPilot-0.1.0-win.zip` 到 Release 附件。源码由 GitHub 自动生成。
6. 如需在线演示，执行 `npm run demo:build`，只部署 `dist/demo/`，核对托管后的流程及响应头。部署成功后再把真实访问链接加入 README。

CI 和本地检查使用模拟数据，不代表真实搜索质量、AI 点评准确率、节省时间或用户留存已验证。验证结果见[本轮规格](../specs/first-public-release.md)。
