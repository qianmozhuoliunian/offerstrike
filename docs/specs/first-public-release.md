# 规格：初版 GitHub 发布准备

- 状态：实现完成，本地验收通过；远端发布待执行
- 最后更新：2026-11-14

## 问题与目标

首次访问仓库的求职者和开发者需要看懂产品边界，独立启动并完成一轮练习。现有说明混合了上手、实现和实验细节，缺少配置模板与持续检查。

## 已确认、假设与待决定

- 已确认：准备发布初版，完成最后一轮优化；采用 MIT 授权。
- 假设：本轮以本机单用户版本为发布对象，在线只分享隔离静态演示。
- 未提供 GitHub 仓库地址，本轮准备本地提交和发布说明，不创建远端仓库。

## 本次范围

- 首页按当前岗位、来源和题库状态给出下一步；说明离线功能和可选服务。
- README 精简为定位、快速体验、首次练习、能力边界和文档导航；详细说明迁入使用指南。
- 配置模板、MIT 许可、贡献与安全说明、首发说明。
- GitHub CI、源码发布隐私检查和独立演示构建检查。

## 本次不做

新增业务模块、改推荐算法或数据格式、重写架构、宣称搜索质量或用户留存已经验证。

## 数据与外部服务影响

不改变数据库与备份格式。页面引导只读取现有状态。CI 使用合成测试数据，不配置真实服务密钥；隐私检查不输出命中内容。

## 执行记录与限制

GitHub 托管 CI、干净 Windows 安装、真实搜索和 AI 质量需分别验证，不能由本地模拟测试替代。

- 浏览器验收发现新增 ES 模块没有加入服务器静态路由，已修复，并新增前端模块依赖图的 HTTP 回归检查。
- README 明确区分预置演示、离线练习和需要个人服务配置的能力；首页配置状态不等同于外部连接已验证。
- 不改变数据保存格式、推荐算法或已有备份；没有导入真实简历或真实个人面经用于验收。
- 公开源码仍需人工核对个人文字和图片。自动扫描只覆盖常见敏感文件名及密钥格式，不提供绝对无隐私信息的保证。
- 最终源码扫描通过：143 个文件、306 个暂存或历史内容对象；主要发布文档的 24 个本地链接目标均存在。
- Windows 安装器和 ZIP 已重新构建；受当前环境下载限制，使用本机已安装的 Electron：`npm run desktop:build -- --config.electronDist=node_modules/electron/dist`。应用归档包含 LICENSE 和新增引导，未发现数据库、环境配置或日志路径。安装器仍未签名，也未在干净机器安装。
- 本次桌面产物来自当前工作区，含原先未提交的两处资料库样式调整；正式 Release 仍应按发布说明从指定提交重新构建。
