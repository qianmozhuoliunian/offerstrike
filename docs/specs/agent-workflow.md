# 规格：从面经研究到备战计划

- 状态：实现完成；真实双源与人工质量评估待完成
- 方案：[Agent 架构升级](../agent-architecture-upgrade.md)

研究是独立于快速搜索的可选操作。用户确认公开主题后，限定两轮、四次搜索、两次文章读取、三次模型调用、75 秒；达到证据覆盖、无新候选或预算用尽时停止。成功结果缓存五分钟；重试只在同一预算内换查询或供应商。只读取允许的博客园正文，无法读取则保留链接并引导原有手动粘贴。模型仅收到明确披露的正文范围。没有正文摘录的题不能成为证据候选；确认前无题库写入。

备战先复用岗位要求、题库、练习、点评和自评。用户选择主题后，按已有作答和自评排序，可选择多题模拟并逐题复盘；主动粘贴简历才做证据约束的能力提取，原文和结果不自动持久化。备战建议实时从已有资料重算，不增加数据库表。保持旧备份和手动操作兼容。

验收：测试有限补搜、失败降级、证据、个人数据范围、同岗位隔离、不同自评调整训练和旧备份；用隔离数据走网页流程。运行固定评估任务，分别记录模拟、真实调用和人工核对，费用缺数据时标为未知。

[本轮验收记录](../agent-evaluation.md)列出真实抽查和 20 项对照。固定集证据产出未达到上线门槛，保留快速搜索为默认。
