# 规格：统一页面暖色视觉与插画

- 状态：已完成
- 最后更新：2026-11-12

## 问题与目标

工作台已采用柔和背景和学习场景插画，其他页面的视觉层次与其不一致。求职者需要在不同页面都能感受到统一、温暖的界面，同时轻松阅读题目、结果和表单。

## 已确认、假设与待决定

- 已确认：用户希望所有页面延续工作台的背景、层次和配图风格。
- 假设：各页面可以使用与用途相关的装饰插画，保持相同的色彩和视觉语言；插画不承担必要信息。
- 待决定：无阻碍实施的事项；视觉风格以实际呈现和用户反馈调整。

## 本次范围

- 将工作台的暖色视觉延伸至搜索面经、练习与点评、资料库、岗位设置、面试复盘以及偏好与状态页面。
- 根据页面用途安排装饰插画、背景和标题层次，提供与页面适配的本地图像资源。
- 考虑桌面和窄屏布局、文字可读性、导航和其他可操作控件。

## 本次不做

- 不改变岗位、面经、题目、复习、导入导出或 AI 服务的业务逻辑与数据语义。
- 不将装饰图作为交互入口或必要信息，也不添加自动播放或遮挡操作的视觉效果。

## 验收标准与验证

| 可观察的完成标准 | 验证方式 | 结果 |
| --- | --- | --- |
| 各页面均与工作台呈现一致的暖色背景、层次和配图风格，配图不会遮挡文字 | 在浏览器逐页检查实际呈现 | 通过：桌面端逐页检查六个页面 |
| 页面导航、表单及主要操作仍可定位和使用，装饰图不拦截交互 | 浏览器抽查导航、输入和已有入口 | 通过：六页导航及资料库录入弹窗可打开；表单提交未逐项人工实测 |
| 窄屏下图片和内容合理换行，无新增横向溢出 | 使用窄屏视口检查布局 | 通过：390px 视口逐页截图，文档宽度均为 390px |
| 图片资源正常加载，现有自动化测试通过 | 检查资源请求并运行 `npm test` | 通过：三张插画返回 HTTP 200；79 项测试通过 |

## 数据与外部服务影响

界面使用本地图片资源，不增加用户数据、面经内容或练习回答向外部服务的发送。图片生成仅使用描述场景的提示词，不包含用户个人数据。数据迁移与备份兼容性不受本次改动影响。

## 执行记录与限制

桌面和 390px 视口使用隔离数据预览；未逐项人工提交表单，也未调用真实外部 AI 或搜索服务。插画由内置图像生成工具根据不含个人数据的场景描述生成。
