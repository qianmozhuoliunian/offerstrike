# v0.1.0 · 早期试用版

面试突击（OfferStrike）的首版：按岗位找公开面经，核对原帖收题，作答并自评，再查看下一次推荐。

## 本版包含

- 按岗位管理题库，查看题目来源，保存作答并自评。
- 按自评和练习记录推荐下一题，支持草稿恢复、面试复盘与 JSON 备份。
- 提供本地网页、Windows 桌面入口和独立静态演示。

## 试用前了解

- 手动练习无需密钥。搜索需自行配置 Tavily 或 Exa；AI 功能需配置模型服务。结果请人工核对，费用取决于供应商。
- 工作台仅供本机单用户使用。Windows 包未签名，无自动更新，尚未验证在未装过旧版的电脑上安装。

## 维护者首发步骤

1. 运行 `npm run check`，人工核对文档、图片和提交作者信息。修改 Python 检索服务时另跑其测试。个人数据、密钥和构建包不进 Git。
2. 推送源码到目标仓库。等 GitHub Actions 的 Windows 和 Ubuntu 检查通过，再从该提交创建 `v0.1.0` 标签和 Release。
3. 如提供 Windows 附件，从同一提交按[打包说明](../desktop-and-demo.md)重建 EXE 和 ZIP。要上线体验页，只部署 `dist/demo/`，验证后再公开链接。
