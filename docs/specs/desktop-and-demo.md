# 规格：公开体验与 Windows 工作台

- 状态：已完成（本机试用与静态产物）
- 最后更新：2026-11-14

提供独立静态体验和完整 Windows 应用。体验页用标注来源的示例与共享推荐规则，回答和自评仅在当前页面，不请求工作台 API 或外部模型。完整工作台保留 `npm start`，桌面应用自带运行时、启动和关闭本机后端，使用独立用户数据目录。旧数据可用既有 JSON 备份迁移。服务密钥通过桌面设置写入操作系统加密存储，不回显、不随备份和安装包分发。

已设置岗位时，用户可不调用模型就保存一次完整作答并自评；历史可主动补点评，仍更新同一条记录。首页提供恢复草稿及查看今日建议的操作。备份继续用 v1，保存未点评状态和稳定题目关联。网页公开部署及发布下载由发布步骤单独处理。

验收：两个独立浏览器会话完成体验且无 API 访问；桌面打包启动、旧备份导入、重开保留数据、未点评作答可备份恢复、后端随退出关闭。验证密钥不进入导出和打包内容。说明未在干净 Windows 环境验证的部分。

2026-11-14 验证：Node 118 项通过，覆盖未点评作答重试去重、备份恢复、题目关联和自评。Edge 在两个隔离会话走完不同自评分支，未请求工作台 API 或外部服务，390px 宽度无横向溢出。Windows 实际打包程序用隔离数据导入旧版 v1 备份、恢复草稿、无 AI 配置时保存和自评，关闭重开后用本机模拟 AI 为同一条作答补点评；最后输入的草稿在关闭窗口后可恢复，退出后后端停止。加密设置未回显，备份及打包内容未包含密钥或工作区数据库。

限制：安装包未签名，已验证其同次构建的打包程序，未在干净 Windows 机器上完整安装或升级。网页已生成静态产物，未公开部署。发布说明见 [桌面版与公开体验页](../desktop-and-demo.md)。
