## 本机服务与数据流

使用隔离数据库的 23 项测试通过，包含新增的两个隐私边界用例与既有工作区测试。

- `/api/state`、工作区、导出、历史与训练任务均要求访问凭证，移除凭证返回 401，查询参数不能替代请求头凭证。错误 Host、Origin 与跨站请求被拒绝。
- 静态资源入口不能读取根 `.env`、SQLite 或后端源码，未公开 OpenAPI 文档。私有接口返回禁止缓存与禁止发送 Referrer 的响应头。
- 用户主动导出的备份包含自己的回答，但不包含模型或搜索服务密钥。模型服务错误和输入校验错误不会把密钥或回答原文回显给前端。
- 模型密钥只在后端传输或桌面系统加密配置中使用。前端记录临时本机访问凭证，不保存外部 API Key。桌面设置只回传配置状态，不回传原密钥。
- AI、搜索和简历处理仍会向用户选择的供应商发送界面披露的内容，属于功能所需外部传输。未发现新增分析、追踪或广告脚本。

## 边界

本产品仍是本机单用户服务，不应直接暴露公网。SQLite 与 JSON 备份未做整库加密，本地 `.env` 是明文，保留在本机并不等于被删除。当前系统账号下的恶意程序、已公开的 Git 历史身份信息和供应商端的数据处理不在本次源码发布保证范围内。此次只推送源码，不上传安装器、个人资料或原始本机测试输出。
