# 面经研究与备战：使用与验收

在搜索页展开「深度研究」，沿用上方筛选，填写你愿意公开的主题。点击「确认并研究」；检查摘录与原帖后再入库。没有证据时，可用快速搜索或手动添加来源。当前支持博客园文章和公开可用的牛客讨论帖正文，其他平台显示链接。默认最多两轮、四次检索、两次读取、三次模型调用和 75 秒。每篇向模型发送正文前 6000 个字符，模型输入总量以 UTF-8 字节上限约束，输出每次最多 800 token。记录服务商、工具耗时、成功/失败与可获得的 token 用量；没有供应商费用数据时记为未知。完整覆盖的结果可复用 5 分钟，过期候选须重新研究。

练习页展开「备战计划与多题模拟」。主题留空时使用已确认岗位要求和历史自评；可自行指定主题。缺题时可带主题返回研究页，发送前核对关键词。三题模拟复用单题问答与点评，完成后集中展示本场总结；本场进度只保留在页面内，每题记录继续存 SQLite。可主动提取简历能力线索，人工确认后用作训练主题。简历不保存、不参与自动搜索，摘录不是熟练度评分。

快速搜索与深度研究都可使用现有 FastAPI 检索配置。Node 继续控制查询、预算、原帖读取与模型调用，也是唯一数据所有者。已确认题目和来源使用原有 v1 备份结构。配置 FastAPI 后，检索失败会在页面提示，请检查 Python 服务、访问凭证和上游配置。

若需要金额硬上限，给 `RESEARCH_COST_BUDGET` 配置 JSON，包含 `limit`、`Tavily`、`Exa`、`model` 四个非负整数，单位为微美元。后三项按供应商实际计划填写单次调用的保守上界，程序在调用前预扣，失败调用也计入预算；预扣不等于实际账单。未配置时仍有工具次数和输入输出预算，但没有美元硬上限。

设置 `RESEARCH_LOG=1` 可让 Node 输出每次研究的 JSON 日志，包括停止原因、各工具耗时与状态和结果数量。日志不包含岗位、公司、主题、正文、简历或密钥。

```powershell
npm ci
npm test
node scripts/research-eval.mjs
node --env-file-if-exists=.env scripts/research-eval.mjs --live --limit=2
```

不带 `--live` 只列出 20 项固定任务。实测会消耗服务额度；移除 `--limit` 可执行完整集合。输出 JSONL，区分 Tavily 基线、当前多源与深度研究，没有 Exa 凭据时多源一列为空。人工复核链接可读性、原帖类型、岗位、公司、日期和逐字证据，补填有效题数、错误来源数与账单数据。自动计数和候选数量不能代替人工核对。

2026-11-13 验收结果：

| 检查 | 结果 |
| --- | --- |
| 自动化回归 | Node 117 项、FastAPI 14 项通过。覆盖有限补搜、故障降级、预算、候选确认、自评调整、简历摘录与备份恢复 |
| Edge 网页（模拟上游、隔离数据） | 搜索并查看摘录、核对入库、生成备战计划、完成 3 道不同题并回顾、简历能力提取后转为主题；390px 下无横向溢出 |
| 真实证据链抽查 | [腾讯公开前端岗位](https://careers.tencent.com/zh-cn/jobdesc.html?postId=2088182151676870656)列有 React。以「腾讯 / 前端开发 / React / 博客园 / 不限时间」发起研究，检索、正文读取、AI 各 1 次，约 9.6 秒，1 道带逐字摘录的候选。[原帖](https://www.cnblogs.com/huansky/p/5973655.html)涵盖多家公司，不能认定这道题由腾讯提问 |
| 固定 20 项，Tavily 基线 | 3 项有初筛主结果，共 9 条；8 项至少一路失败。结果未经逐篇人工核对 |
| 固定 20 项，深度研究 | 230 条待核实链接，**0 道证据候选**。40 次搜索、0 次正文读取、0 次提取；没有链接同时满足当前阅读平台与相关性、类型和日期条件。19 项达到轮次上限，1 项无候选；约 11.6–23.3 秒/项 |

这组结果只证明流程在受支持的原帖上能跑通，**不支持替换默认搜索或声称质量有提升**。当前 20 项中 10 项明确选择牛客或掘金，二者都还不支持自动读正文。下一步应按真实返回先验证一个主要平台的正文读取方式，再重跑相同任务。未配置 Exa，双源真实对照、人工错误率及账单成本仍未验收。

## 博客园证据复核试点

将已核对使用范围的博客园文章 URL 加入服务进程的 `RESEARCH_PILOT_URLS`，用英文逗号分隔。重启 Node 和已启用的 FastAPI，在搜索页将来源选为「博客园」后运行「深度研究」。试点只读取列表中的文章，其他结果仍可作为原帖链接手动查看。选择博客园但未配置试点文章时沿用原流程。

使用相同模拟搜索响应、文章 HTML 和候选模型输出回放新旧两条路径。准备好搜索与 AI 的配置和试点链接后，可显式运行真实对照。真实对照会调用搜索供应商和模型，输出的候选需人工核对，实付费用按供应商账单补录。

```powershell
node scripts/research-eval.mjs --replay
node scripts/research-eval.mjs --pilot
node --env-file-if-exists=.env scripts/research-eval.mjs --pilot --live --limit=2
```
