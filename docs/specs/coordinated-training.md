# 规格：训练任务协作

- 状态：已完成

## 范围

Career 的补题建议由用户创建为当前岗位的训练任务。Research 接收任务的关键词及用户选择的搜索范围，复用原文读取、证据核验和人工确认。Interview 通过已确认的题目 ID 回传结构化作答。Career 从同一份历史重算下一轮计划。

## 契约

- 任务包含岗位、主题、知识点、创建请求编号和状态，依次记录可核对候选、已入库题目及完成作答。现有推荐、手动研究和练习接口可独立使用。
- 状态为 `proposed → searching → review → ready → completed`，异常结束为 `failed` 或 `cancelled`。创建、搜索重放和确认入库支持重试。每个任务至多一次 Research 运行，沿用 75 秒、2 轮、4 次检索、2 次读取、3 次模型调用的预算。失败后可由用户创建新任务。
- 搜索中断留下的任务在 80 秒租期到期后标为失败，已保存候选和人工确认结果可恢复。任务位于同一 SQLite 库。JSON 备份继续保存题目、证据和作答，补题任务状态属于本机。
- `GET /api/training/tasks?role=…` 查看本岗位任务。追加 `id` 可查看单条任务的候选、题目与作答关联。`POST /api/training/tasks/create` 读取 Career 建议并建立待确认任务，`POST /api/training/tasks/cancel` 可取消任务。Research 的现有执行和确认接口接受可选的 `task_id`。
- 确认入库使用同一个事务写入证据和任务状态。Interview 保存可核对评价时，通过稳定题目引用完成任务。用户仍可继续当题追问，下一轮 Career 根据新评价重新生成。
- 能力画像使用按主题限定的明确别名。不会把不同指标、检索评估和生成评估合并。原始摘录和原标签仍保留。

## 验收

- Node 全量回归通过 156 项。
- 模拟模型与检索通过 AI Agent 开发实习场景。题库已有 RAG 基础题，但缺检索评估题。人工确认、重启和作答后，Career 从补题变为练习。原始的「检索评估」与「检索质量评估」共同形成改善记录。召回率与生成质量评估保留单独的记录。
- 自动覆盖搜索无结果、证据不匹配、两处模型失败、用户取消、超时恢复、重复提交、岗位隔离和 v2 数据库迁移。
