## 问题与目标

## 已确认、假设与待决定

- 已确认：优先修复备份恢复一致性和点评输入截断，再建立 Git 基线。
- 假设：对新的点评请求明确限制问题 2000 字、回答 10000 字；超限时保留输入并提示修改，不发送部分内容。
- 假设：历史上已保存的长字段需要兼容恢复；不迁移或修改用户现有数据。
- 待决定：无。
