# 规格：核心流程梳理与稳定

- 状态：草稿
- 最后更新：2026-11-11

## 问题与目标

项目已包含岗位设置、面经搜索、来源与题目管理、练习等功能，功能逐步增加后，需要确认求职者能否顺畅地从目标岗位走到一次有来源的练习。先找出阻碍核心流程的问题，并为后续小步修复提供依据。

## 已确认、假设与待决定

- 已确认：产品设计中的核心流程包括目标岗位、搜索面经及后续复习；来源需可追溯，信息未知时不能编造。
- 已确认：当前项目是本地单用户原型，具体已实现功能以代码和 README 为准。
- 假设：先检查岗位设置 → 搜索 → 保存来源 → 整理题目 → 练习这一条路径，可以较快发现最影响使用的断点；待实际操作验证。
- 待决定：检查完成后，哪些问题优先修复，以及修复是否需要单独规格。

## 本次范围

- 检查上述流程及岗位切换、服务未配置或请求失败时的用户可见行为。
- 记录每一步的观察、复现方法、影响和验证条件，区分实际发现与推测。
- 按用户影响提出优先级和适合小步处理的建议；是否进一步修复由具体任务范围决定。

## 本次不做

- 不新增搜索平台、模拟面试或简历优化功能。
- 不重写整个项目、不改变推荐规则或迁移用户数据。
- 不以模拟服务测试结果代表真实搜索或模型质量。

## 验收标准与验证

| 可观察的完成标准 | 验证方式 | 结果 |
| --- | --- | --- |
| 核心路径每一步都有实际操作结果，无法执行的步骤说明原因 | 在本地运行并逐步操作，记录条件和结果 | 未验证 |
| 岗位切换、服务未配置及失败场景得到检查，未覆盖项明确列出 | 结合实际操作和相关自动化测试 | 未验证 |
| 问题清单包含复现方式、用户影响和建议优先级 | 检查记录能否支持后续定位与取舍 | 未开始 |
| 已有资料得到保留，测试使用隔离或可清理的数据 | 检查操作和测试的数据位置 | 未验证 |

## 数据与外部服务影响

检查前确认所用数据位置，避免修改用户现有资料。真实搜索和 AI 点评会向外部服务发送 README 所述信息；仅在配置和使用条件允许时验证，未调用的部分标明限制。
